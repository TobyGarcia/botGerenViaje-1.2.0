# Gerenciamiento de Viajes

Sistema para administrar salidas y viajes de vehículos.

## Tecnologías

- React
- Node.js
- Express
- PostgreSQL
- Docker
- ngrok
- Telegram Mini App

## Módulos iniciales

- Catálogo de conductores
- Catálogo de vehículos
- Catálogo de lugares
- Registro de viajes
- Inicio y finalización de viajes
- Rastreo GPS
- Historial de estados
